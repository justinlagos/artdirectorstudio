# Enable Anonymous Authentication in Supabase

To allow document creation without requiring users to sign in, you need to enable anonymous authentication in Supabase.

## Steps:

1. Go to your Supabase Dashboard: https://supabase.com/dashboard/project/vsbjxktlrbfxfhxiqzlr
2. Navigate to: **Authentication** → **Providers**
3. Find **Anonymous** in the list of providers
4. Click **Enable** toggle
5. Click **Save**

## Alternative: Use Regular Sign-In Instead

If you prefer not to use anonymous auth, users can sign in normally and then create documents. The Canvas page is accessible without login, but document creation will require authentication.
