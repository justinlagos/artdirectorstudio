# External Integrations

## APIs & External Services

**Supabase Edge Functions:**
- Listed in `src/lib/edgeFunctionHealth.ts`: `documents`, `actions`, `assets`, `generate-image`, `analyze-image`, `artie-chat`, `edit-image`, `blend-images`, `upscale-image`, `check-feature-access`, `create-checkout-session`, `create-subscription-checkout`, `create-portal-session`

- Base URL: `{VITE_SUPABASE_URL}/functions/v1/{function-name}`

## Data Storage

**Databases:**
- **Type:** PostgreSQL (hosted on Supabase)
- **Connection:** Via Supabase client in `src/integrations/supabase/client.ts`
- **Auth:** `VITE_SUPABASE_PROJECT_ID`, `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`
- **Client:** `@supabase/supabase-js` v2.77.0
- **Key Tables (auto-generated schema in `src/integrations/supabase/types.ts`):**
  - `generated_assets` - User image generation history
  - `profiles` - User profile data (subscription_tier, free_credits)
  - `community_posts` - Community user-generated content
  - `community_likes` - Post engagement
  - `community_comments` - Post comments
  - `community_follows` - User relationships
  - `performance_metrics` - System monitoring
  - Others as per auto-generated types

**File Storage:**
- **Provider:** Supabase Storage (PostgreSQL-backed object storage)
- **Usage:** Image uploads, asset storage
- **Access:** Via `supabase.storage.from(bucketName)` calls
- **Locations:** `src/components/ArtieChat.tsx`, `src/hooks/useArtieCore.ts`, `src/lib/saveAsset.ts`, `src/components/brand/BrandKitUpload.tsx`, `src/hooks/canvas/useCanvasDropZone.ts`
- **Auth:** Bearer token from authenticated session

**Caching:**
- **Local Storage:** Session persistence, user preferences (via `localStorage` in auth config)
- **React Query Cache:** Server state with configurable stale times (5-10 min for queries)
- **Service Worker Cache:** Via Workbox for offline access

## Authentication & Identity

**Auth Provider:**
- Supabase Auth (PostgreSQL-backed)
- Session-based with JWT tokens

**Implementation:**
- `src/contexts/AuthContext.tsx` - React context providing user, session, signUp, signIn, signOut
- `src/integrations/supabase/client.ts` - Configured with localStorage persistence and auto-refresh
- Auth state listener: `supabase.auth.onAuthStateChange()`
- Token storage: localStorage (configured in client init)

**Session Management:**
- Access token stored and auto-refreshed
- Session retrieved via `supabase.auth.getSession()`
- User info via `supabase.auth.getUser()`

## Monitoring & Observability

**Error Tracking:**
- **Service:** Sentry (`@sentry/react` v10.25.0)
- **Config:** `src/lib/sentry.ts`
- **DSN env var:** `VITE_SENTRY_DSN` (optional - gracefully skipped if not provided)
- **Setup:** Async initialization (non-blocking) in `src/main.tsx`
- **Integrations:** Browser tracing (10% sample rate), Session replay (10% session, 100% on error)
- **Filtering:** Network errors filtered out to reduce noise

**Analytics:**
- **Service:** Mixpanel (`mixpanel-browser` v2.72.0)
- **Config:** `src/lib/analytics.ts`
- **Token env var:** `VITE_MIXPANEL_TOKEN` (optional)
- **Setup:** Async, non-blocking initialization
- **Tracking:** Custom events with sanitized properties (no PII), user identification, property tracking
- **Usage locations:** `src/contexts/AuthContext.tsx` (sign in/out), component-level tracking

**Performance Monitoring:**
- Supabase performance metrics table (`src/lib/performanceMonitoring.ts`)
- Web Vitals tracking via `web-vitals` library
- Edge function health checks in `src/lib/edgeFunctionHealth.ts`

**Logs:**
- Browser console (dev mode warnings for configuration issues)
- Sentry captures exception logs

## Environment Configuration

**Required env vars (production):**
- `VITE_SUPABASE_PROJECT_ID` - Supabase project reference (e.g., "gpyxglipegxukulmqykv")
- `VITE_SUPABASE_URL` - Supabase API endpoint (e.g., "https://gpyxglipegxukulmqykv.supabase.co")
- `VITE_SUPABASE_PUBLISHABLE_KEY` - Supabase anon/publishable key for client-side auth

**Optional env vars:**
- `VITE_SENTRY_DSN` - Sentry error tracking (gracefully skipped if missing)
- `VITE_MIXPANEL_TOKEN` - Mixpanel analytics (gracefully skipped if missing)
- `VITE_CLOUDFLARE_ACCOUNT_ID` - For future CDN integration (not yet implemented, see `src/lib/cdn.ts`)

**Secrets location:**
- `.env` file (git-ignored, local development)
- Environment variables set in deployment platform (GitHub Pages/Vercel/etc)

**Validation:**
- Supabase client validates configuration on init (`src/integrations/supabase/client.ts` includes runtime validation)
